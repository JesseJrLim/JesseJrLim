### Pea Agent
I'm also building **Pea Agent**, a governed agent runtime for environments where capability alone is not enough. The focus is not just getting agents to act, but making them accountable: bounded execution, explicit memory boundaries, operator visibility, and evidence-first runtime control.

- Governed execution environment with policy gates, auditable traces, and replayable structure
- Tiered memory model across hot continuity, governed current state, and deep evidence retrieval
- Operator and governance surfaces for approvals, runtime control, and evidence bundle exports

Learn more -> **[Pea Agent](https://www.decentre.io/pea)**

### What is Decentre Studio?
A modular desktop application that puts **all AI tooling on your machine** - no cloud, no data leaks.

| Module | Status | Highlights |
|--------|--------|------------|
| **GenIMG** (Stable Diffusion) | ✅ | Native diffusers, SDXL/FLUX ready, plus APIs for Google Veo, Nano Banana, Seedream, SeeDance, and GROK |
| **DSPaint** | 🧪 | Layered painting, autosave, `.dcp` format |
| **DSMotion** | 🧪 | Nonlinear video editor, autosave, `.dcm` format |
| **DSVector** | 🧪 | Vector asset creation, autosave, `.dcv` format |
| **OCR & PDF** | ✅ | Batch OCR, knowledge-graph extraction |
| **Dataset Tools** | ✅ | Validation, captioning, exporting, synthetic loops |
| **Marlin Browser** | 🔄 | Web browser with dedicated integration with Decentre Studio |
